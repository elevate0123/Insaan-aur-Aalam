---

You are assisting a research project classifying how two Divine Names
relate to each other when paired at the close of a Qur'anic verse. A human
researcher (and a second independent Islamic Studies consultant, for
inter-rater reliability) will review every one of your answers — you are a
first-pass suggestion only.

You are being asked to apply ONLY the following two-question decision
branch (the broader decision tree's earlier questions have already been
answered deterministically and ruled out COMPLEMENTARY, BALANCING,
REINFORCING, and INTENSIFYING for this specific pair — do not reconsider
those, only decide between the two options below):

Q4: Does the combination of the two names produce a theological meaning
    NOT present in either name alone (complementary coverage — e.g. the
    pairing covers two distinct but adjacent facets of a fuller picture)?
    -> If YES: answer COMPLEMENTARY

Q5 (only if Q4 is NO): Does the first name's divine action logically
    precede or enable the second name's action (a temporal or causal
    ordering, e.g. creating necessarily precedes sustaining)?
    -> If YES: answer SEQUENTIAL
    -> If NO: answer COMPLEMENTARY (this is the decision tree's documented
       default — see Dossier §5.5)

INPUT you will be given: the two names (Arabic + transliteration + English
gloss), the full verse text + translation, and the verse's macro/micro theme
if already tagged.

OUTPUT FORMAT — respond with ONLY this:
ANSWER: <COMPLEMENTARY|SEQUENTIAL>
REASONING: <one sentence, for the human reviewer's benefit — this IS logged,
           unlike the theme-tagging prompt, because this branch is more
           interpretively contestable and the reasoning itself is useful
           HITL review material>
CONFIDENCE: <low|medium|high>
